# Airlines Reservation System ✈️

## Overview 🌍

This project is a flight booking system that allows users to search for flights, book tickets, and manage reservations. Admins can add flights, view bookings, and manage user data using **Django’s built-in ORM**. It also includes role-based access control for secure login. 🔐

## Features ✨

- **Flight Search & Booking**: Users can search available flights and book tickets. 🛫
- **Admin Panel**: Admins can add flights, manage bookings, and view user data. 🧑‍💼
- **Role-Based Authentication**: Secure login and access control using **Django Authentication System** 🔑.

## Technologies Used 💻

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python, Django
- **Database**: SQL (for storing flight and user data)

## Installation ⚙️

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/airlines-reservation-system.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the server:
   ```bash
   python manage.py runserver
   ```

## How It Works 🔄

- Users can search for flights, make bookings, and manage reservations via the web interface. ✈️
- Admins have a dashboard to manage flights, view bookings, and control user access. 🛠️
- Secure user authentication and role-based access ensure that each user has the appropriate permissions. 🔐
